# FyFlade name and logo policy

The GNU GPL license applies to FyFlade's source code. It does not grant permission to use the FyFlade name, logo, or other project branding in a way that suggests an unofficial or modified build is an official FyFlade release.

You may accurately state that a project is based on FyFlade. If you distribute a modified build, you must give it a clearly different product name and icon unless you have written permission from the FyFlade project.

Only release files published through FyFlade's official website or official project accounts may be described as official FyFlade releases.
